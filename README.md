# Cnotext

![Cnotext](assets/cnotext-logo.png)

Это утилита для быстрого преобразования живых изображений в $\LaTeX$ конспекты.

По сути обертка на OpenCode с инструкциями и блоками LaTeX с контекстом, из которых LLM должна собирать файл.

Установка ставит TeX, Opencode и по мелочи, а также все пакеты для TeX. Пока только для MacOS (Homebrew)

> Я очень не люблю разбираться в своем рукоблудии после пар, поэтому оставил грязную работу на LLM.
