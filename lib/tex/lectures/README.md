# Референсы лекций

Эта директория содержит референсы общей композиции лекционных конспектов.
Они показывают, как в целом выглядит документ, в котором материал раскрывается
через смысловую иерархию.

## Что определяет референс

- оформление заголовка и метаданных занятия;
- уровни разделов и подразделов;
- типографику основного текста;
- вертикальные отступы;
- нумерацию разделов;
- общую плотность и композицию документа.

## Что референс не определяет

- обязательный набор разделов;
- содержимое лекции;
- используемые bricks;
- порядок смысловых блоков;
- наличие определений, теорем, формул, схем и других локальных элементов.

Структуру конкретной лекции необходимо восстанавливать по всему исходному
материалу. Не следует добавлять раздел или подраздел только потому, что он есть
в примере.

## Как использовать

1. Определи фактические метаданные и иерархию материала по исходнику.
2. Возьми `reference.tex` или ближайший пример как основу композиции.
3. Удали демонстрационный текст и отсутствующие в исходнике метаданные.
4. Сохрани только те уровни заголовков, которые выражены в исходнике.
5. Для каждого нетривиального локального блока отдельно выбери подходящий
   компонент из `../bricks/` и прочитай его документацию.

Файлы в этой директории не являются библиотекой определений, теорем, формул,
графиков или схем. Такие элементы принадлежат `../bricks/`.

> Lecture reference отвечает за макроструктуру. Bricks отвечают за локальные
> элементы. Исходный материал отвечает за фактическую структуру конкретного
> документа.

## Файлы

- `reference.tex` — основной референс лекционного документа;
- `examples/simple.tex` — короткая лекция без искусственного дробления;
- `examples/sectioned.tex` — лекция с несколькими уровнями смысловой иерархии.

Все `.tex`-файлы самостоятельны и рассчитаны на сборку `xelatex`. Для
кириллицы используется системный шрифт `PT Serif`.
