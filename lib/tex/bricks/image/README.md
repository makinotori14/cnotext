# `image`

Вставка существующего изображения, которое нельзя или не следует
воспроизводить средствами LaTeX: фотография, скан, сложная иллюстрация.
Диаграммы, графики и геометрические чертежи по возможности набирайте
соответствующими кирпичиками, если это повышает читаемость и сохраняет смысл.

## Зависимости и шаблон

```latex
\usepackage{graphicx}

\begin{figure}[ht]
  \centering
  \includegraphics[width=.72\linewidth]{images/source-page.png}
  \caption{Подпись из источника}
  \label{fig:source-page}
\end{figure}
```

Путь должен быть относительным к итоговому `.tex`. Сохраняйте пропорции; не
задавайте одновременно `width` и `height` без `keepaspectratio`. Обрезку через
`trim=left bottom right top,clip` применяйте только после визуальной проверки.

Примеры используют локальный векторный файл `assets/sample.mps` только чтобы
оставаться автономно компилируемыми. Формат MPS поддерживается `pdfLaTeX`
напрямую, без Ghostscript. В реальном документе замените его относительным
путём к исходному изображению.

## Примеры

- [`figure.tex`](examples/figure.tex) — рисунок с подписью и ссылкой;
- [`cropped.tex`](examples/cropped.tex) — контролируемый размер и обрезка.
