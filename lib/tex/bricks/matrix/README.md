# `matrix`

Матрицы, векторы-столбцы, определители и расширенные матрицы. Тип скобок
выбирается по исходнику: `pmatrix` — круглые, `bmatrix` — квадратные,
`vmatrix` — определитель. Не используйте `array` с нарисованными вручную
скобками без необходимости.

## Зависимости

```latex
\usepackage{amsmath}
```

Столбцы разделяются `&`, строки — `\\`. Для расширенной матрицы `array`
внутри `\left[...\right]` позволяет обозначить смысловой разделитель.
