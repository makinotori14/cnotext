# `number-line`

Числовая прямая с точками, интервалами, лучами и знаковыми промежутками.
Выбирайте её, когда порядок на одной оси важнее полноценной координатной
плоскости.

## Зависимости

```latex
\usepackage{tikz}
\usetikzlibrary{arrows.meta}
\input{lib/tex/bricks/number-line/commands.tex}
```

Закрашенная точка означает включённую границу, пустая — исключённую. Эти
различия должны следовать источнику. Подписывайте только значимые деления.

## Примеры

- [`interval.tex`](examples/interval.tex) — ограниченный интервал;
- [`sign-chart.tex`](examples/sign-chart.tex) — знаковая схема.
