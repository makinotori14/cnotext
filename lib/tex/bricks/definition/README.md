# `definition`

Семантическое определение нового понятия или обозначения. Выбирайте этот
кирпичик, когда блок отвечает на вопрос «что называется…» и должен участвовать
в нумерации и перекрёстных ссылках. Не используйте его для неформального
пояснения — для него подходит обычный текст или `remark`.

## Зависимости и подключение

```latex
\usepackage{amsthm}
\usepackage{tcolorbox}
\tcbuselibrary{breakable}
\input{lib/tex/bricks/definition/commands.tex}
```

`commands.tex` создаёт окружение `definition`, нумеруемое внутри раздела.
Необязательный аргумент — название понятия. Метку ставьте сразу после начала
окружения.

```latex
\begin{definition}[Metric space]\label{def:metric}
  ...
\end{definition}
```

Сохраняйте формулировку и обозначения источника. Не превращайте свойство,
теорему или соглашение об обозначениях в определение без смысловых оснований.

## Примеры

- [`simple.tex`](examples/simple.tex) — короткое определение с формулой;
- [`boxed.tex`](examples/boxed.tex) — именованное определение со ссылкой.
