# `derivation`

Последовательная цепочка равенств, неравенств или эквивалентных
преобразований, где выравнивание показывает ход вычисления. Выбирайте
`align`/`align*`, если каждая строка — шаг цепочки; для нескольких независимых
формул подходит `aligned-math`.

## Зависимости

```latex
\usepackage{amsmath,mathtools}
```

Ставьте `&` перед основным знаком отношения. Пояснение к шагу оформляйте через
`\text{...}` или `\underbrace`, не ручными пробелами. Для одной общей метки
используйте `equation` с вложенным `aligned`; для отдельных меток — `align`.

## Примеры

- [`aligned.tex`](examples/aligned.tex) — ненумерованная цепочка;
- [`comments.tex`](examples/comments.tex) — пояснения к шагам;
- [`long.tex`](examples/long.tex) — перенос длинной выкладки.
