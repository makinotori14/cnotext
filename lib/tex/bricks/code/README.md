# `code`

Фрагменты программного кода, псевдокода с синтаксисом языка, консольный ввод
или конфигурация. По умолчанию используется `listings`: он компилируется без
`--shell-escape`. `minted` выбирайте только если референс уже поддерживает его
и окружение сборки разрешает Pygments.

## Зависимости

```latex
\usepackage{xcolor,listings}
\input{lib/tex/bricks/code/commands.tex}
```

Стиль `note code` включает перенос длинных строк и видимые номера строк.
Передавайте язык через `language=Python` и подпись через `caption`. Код должен
оставаться текстом, а не изображением.

## Примеры

- [`python.tex`](examples/python.tex) — нумерованный листинг Python;
- [`inline.tex`](examples/inline.tex) — короткий код внутри текста.
