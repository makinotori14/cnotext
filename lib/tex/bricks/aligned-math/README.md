# `aligned-math`

Многострочный математический блок с согласованным выравниванием: несколько
условий, формул или строк одного результата. В отличие от `derivation`, строки
не обязаны быть последовательными преобразованиями одного выражения.

## Зависимости и выбор окружения

```latex
\usepackage{amsmath}
```

- `align`/`align*` — строки нормальной ширины с общей точкой выравнивания;
- `aligned` — компактный блок внутри `equation` или `\[...\]`;
- `gather`/`gather*` — центрированные строки без общей точки выравнивания;
- `split` — одна нумеруемая формула, разбитая на строки.

Не ставьте несколько `&` случайно: каждая пара создаёт новую колонку.

## Примеры

- [`conditions.tex`](examples/conditions.tex) — выровненные условия;
- [`single-number.tex`](examples/single-number.tex) — один номер на блок.
