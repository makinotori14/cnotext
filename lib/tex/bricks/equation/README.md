# `equation`

Одна самостоятельная формула, которая образует отдельный смысловой блок.
Используйте `equation` только когда нужен номер или ссылка; для ненумерованной
формулы используйте `equation*` или `\[...\]`. Связанные строки одной цепочки
относятся к `derivation` или `aligned-math`.

## Зависимости и шаблон

```latex
\usepackage{amsmath}

\begin{equation}\label{eq:energy}
  E = mc^2
\end{equation}
```

Метка ставится внутри нумеруемого окружения. Не используйте `$$...$$`: оно
хуже взаимодействует с отступами и нумерацией LaTeX.

## Примеры

- [`unnumbered.tex`](examples/unnumbered.tex) — формула без номера;
- [`numbered.tex`](examples/numbered.tex) — формула с меткой и ссылкой.
