# `geometry`

Геометрический рисунок: точки, отрезки, многоугольники, окружности, углы и
метки равенства. Координаты здесь служат для устойчивой вёрстки, а не являются
данными задачи, если они не указаны в источнике.

## Зависимости

```latex
\usepackage{tikz}
\usetikzlibrary{calc,angles,quotes}
\input{lib/tex/bricks/geometry/commands.tex}
```

Объявляйте значимые точки через `\coordinate`, затем стройте линии по их
именам. Для углов используйте `pic`; для вычисляемых точек — библиотеку
`calc`. Не полагайтесь на визуальную точность рисунка как на доказательство.

## Примеры

- [`triangle.tex`](examples/triangle.tex) — треугольник и угол;
- [`circle.tex`](examples/circle.tex) — окружность, радиус и касательная.
