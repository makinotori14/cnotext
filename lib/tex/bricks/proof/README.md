# `proof`

Доказательство непосредственно предшествующего или явно названного
утверждения. Использует стандартное окружение `proof` из `amsthm`, которое
ставит заголовок и знак окончания. Не помещайте внутрь рамку без требования
референса и не добавляйте отсутствующие в источнике аргументы.

## Зависимости и шаблон

```latex
\usepackage{amsthm}

\begin{proof}
  ...
\end{proof}
```

Для собственного заголовка используйте необязательный аргумент, например
`\begin{proof}[Proof of necessity]`. Длинные вычисления внутри доказательства
набирайте кирпичиком `derivation` или `aligned-math`.

## Примеры

- [`simple.tex`](examples/simple.tex) — короткое доказательство;
- [`multiline.tex`](examples/multiline.tex) — доказательство с выкладкой.
