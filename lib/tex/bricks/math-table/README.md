# `math-table`

Таблица, в которой основное содержание — математические значения, формулы или
соответствия. Она отличается от `table` тем, что столбцы набираются в
математическом режиме и выравниваются по структуре данных.

## Зависимости

```latex
\usepackage{array,booktabs}
```

Тип столбца `>{$}c<{$}` включает математику для каждой ячейки; текстовые
заголовки внутри него оборачивайте в `\text{...}`. Не помещайте всю таблицу в
`$...$`.

## Примеры

- [`values.tex`](examples/values.tex) — таблица значений функции;
- [`identities.tex`](examples/identities.tex) — таблица формул и условий.
