# `cases`

Система условий/уравнений или кусочное определение функции. `cases` ставит
левую фигурную скобку и две колонки; `dcases` из `mathtools` сохраняет
полноразмерные дроби. Не используйте его для обычного перечня формул без общей
скобки.

## Зависимости

```latex
\usepackage{amsmath,mathtools}
```

В кусочном определении первая колонка содержит значение, вторая — условие,
обычно через `& \text{if } ...`. Для системы уравнений применяйте
`\left\{\begin{aligned}...`.

## Примеры

- [`piecewise.tex`](examples/piecewise.tex) — кусочная функция;
- [`system.tex`](examples/system.tex) — система уравнений.
