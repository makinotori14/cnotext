# `enumeration`

Структурированный список, когда порядок, вложенность, исходные метки или
компактность несут смысл. Для обычного короткого перечня достаточно стандартных
`itemize`/`enumerate`; `enumitem` нужен для явной настройки.

## Зависимости

```latex
\usepackage{enumitem}
\input{lib/tex/bricks/enumeration/commands.tex}
```

Определены `steps` для последовательности действий и `conditions` для списка
условий. Ссылки на пункты `steps` работают через `\label` и `\ref`. Не
подменяйте маркированный перечень нумерованным, если порядок не важен.

## Примеры

- [`steps.tex`](examples/steps.tex) — нумерованные шаги со ссылкой;
- [`nested.tex`](examples/nested.tex) — контролируемая вложенность.
