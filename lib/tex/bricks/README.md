# Библиотека кирпичиков LaTeX

Кирпичик — документированный локальный шаблон для одного смыслового блока
конспекта. Он помогает LLM выбрать устойчивую LaTeX-конструкцию, но не задаёт
каркас лекции или семинара и не является готовым содержанием документа.

## Контракт каталога

Каждый каталог содержит:

- `README.md` — краткий контракт для LLM: когда выбирать кирпичик, зависимости,
  рекомендуемый шаблон, параметры и типичные ошибки;
- `examples/*.tex` — автономно компилируемые экземпляры с реалистичными
  данными; демонстрационные данные всегда нужно заменить содержимым исходника;
- `commands.tex` — только если кирпичику нужны собственные команды, окружения
  или единый стиль. Этот файл подключается в преамбуле через `\input`.

Примеры рассчитаны на `pdflatex`. Код самого кирпичика обычно не зависит от
языка документа. Итоговый конспект должен наследовать движок, шрифты и базовый
стиль выбранного референса.

## Как использовать

1. Определить семантическую роль блока и существенные визуальные связи.
2. Прочитать README кандидата и все релевантные примеры.
3. Подключить только перечисленные зависимости и, если он есть,
   `commands.tex`.
4. Скопировать минимальную конструкцию, заменив весь демонстрационный текст.
5. Проверить совместимость с преамбулой референса, собрать PDF и визуально
   проверить результат.

Не выбирайте кирпичик по одной рамке или внешнему сходству. Например,
выделенная формула остаётся `equation`, если она не является утверждением, а
дерево с вероятностями на рёбрах должно быть `probability-tree`, а не `tree`.
