# `venn-diagram`

Отношения множеств: пересечение, объединение, дополнение и включение. Круги
должны обозначать множества, а штриховка — конкретную операцию; для обычной
схемы пересекающихся понятий используйте `diagram`.

## Зависимости

```latex
\usepackage{tikz}
\usetikzlibrary{patterns}
\input{lib/tex/bricks/venn-diagram/commands.tex}
```

Для операций используйте `\clip` в локальной `scope`, чтобы не обрезать
остальной рисунок. Универсум показывайте прямоугольником только если он имеет
смысл в исходнике.

## Примеры

- [`intersection.tex`](examples/intersection.tex) — пересечение двух множеств;
- [`complement.tex`](examples/complement.tex) — дополнение множества.
