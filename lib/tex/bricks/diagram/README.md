# `diagram`

Произвольная схема объектов и подписанных связей: архитектура, причинная
связь, преобразование данных. Выбирайте её, когда блок не является формальным
графом, деревом, блок-схемой или коммутативной диаграммой.

## Зависимости

```latex
\usepackage{tikz}
\usetikzlibrary{arrows.meta,positioning,fit}
\input{lib/tex/bricks/diagram/commands.tex}
```

`diagram node` — содержательный объект, `diagram arrow` — направленная связь,
`diagram group` — необязательная смысловая группа. Подписывайте стрелки, если
тип связи важен. Положение узлов задавайте относительно соседей.

## Примеры

- [`simple.tex`](examples/simple.tex) — линейная схема;
- [`hierarchy.tex`](examples/hierarchy.tex) — ветвление и группировка.
