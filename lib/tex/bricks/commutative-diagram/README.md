# `commutative-diagram`

Математическая диаграмма объектов и морфизмов, где направления стрелок,
подписи и коммутативность имеют формальный смысл. Для неё предпочтителен
`tikz-cd`: он выравнивает объекты как матрицу и даёт устойчивый синтаксис
стрелок.

## Зависимости

```latex
\usepackage{amsmath}
\usepackage{tikz-cd}
```

Ячейки разделяются `&`, строки — `\\`; стрелка `\arrow[r,"f"]` выходит из
текущей ячейки. Метку с противоположной стороны ставьте как `"f"'`. Не
добавляйте стрелку или условие коммутативности, которого нет в источнике.

## Примеры

- [`square.tex`](examples/square.tex) — коммутативный квадрат;
- [`exact-sequence.tex`](examples/exact-sequence.tex) — короткая точная последовательность.
