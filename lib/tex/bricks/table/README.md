# `table`

Обычная текстовая таблица с заголовками, переносимыми ячейками и смысловыми
горизонтальными разделителями. По умолчанию используйте правила `booktabs` без
вертикальных линий. `tabularx` нужен, когда столбцы должны занять доступную
ширину и переносить текст.

## Зависимости

```latex
\usepackage{booktabs,tabularx,array}
```

`table` — плавающее окружение с подписью; `tabular`/`tabularx` — сама сетка.
Если положение блока в конспекте строгое, допускается таблица без float.
Подпись ставьте над таблицей, метку — после `\caption`.

## Примеры

- [`simple.tex`](examples/simple.tex) — компактная таблица;
- [`wide.tex`](examples/wide.tex) — таблица с переносимым текстом;
- [`grouped.tex`](examples/grouped.tex) — сгруппированные колонки.
